# Ximo — Function Objectives

Short objective for each function/section of the app (a few words each).

## Public
- **Waitlist (`/`)** — Captar interesados pre-lanzamiento.
- **Build log** — Mostrar el detrás del proyecto.
- **Términos** — Reglas de uso (demo).
- **Aviso de Privacidad** — Cómo se tratan los datos (LFPDPPP).

## Auth
- **Registro** — Crear cuenta y aceptar privacidad.
- **Login** — Entrar a la cuenta.
- **Olvidé contraseña** — Recuperar acceso.
- **Restablecer contraseña** — Fijar nueva contraseña.
- **Verificar correo** — Confirmar email.
- **Account-status** — Validar acceso y enrutar.
- **Subscribe** — Dar acceso (demo gratis / pago).

## App — núcleo
- **Dashboard (Inicio)** — Resumen y próximos pasos.
- **Comunidad** — Compartir avances entre atletas.
- **Tareas** — Organizar pendientes del proceso.

## App — recruiting
- **Recruiting** — Ver pipeline por etapas.
- **Directorio NCAA** — Explorar programas y coaches.
- **Universidades** — Gestionar universidades objetivo.
- **Coaches** — Seguir contactos con entrenadores.
- **Correos** — Escribir a coaches con plantillas.
- **Documentos** — Guardar archivos del atleta.

## App — desarrollo
- **Progreso** — Registrar y visualizar marcas.
- **Cursos** — Aprender el proceso paso a paso.
- **SAT/TOEFL** — Organizar exámenes académicos.

## App — oportunidades
- **Promocionar marca** — Enviar anuncios a revisión.
- **Campaña** — Ajustar presupuesto y duración.

## App — cuenta
- **Perfil** — Mantener datos deportivos/académicos.
- **Billing** — Ver/gestionar suscripción.
- **Notificaciones** — Recibir y configurar avisos.
- **Settings** — Tema, idioma, exportar/eliminar datos.
- **Ayuda** — Resolver dudas y contactar soporte.

## Admin
- **Moderación** — Aprobar/ocultar contenido.
- **Anuncios** — Revisar anuncios de marca.

## Funciones de sistema
- **Racha diaria** — Premiar uso diario (estilo Duolingo).
- **Webhook Stripe** — Activar suscripción tras pago.
- **Cron recordatorios** — Enviar recordatorios diarios.
- **activate_subscription (RPC)** — Conceder acceso (demo/manual).
- **requireSubscription** — Bloquear app sin acceso.
- **RLS + triggers** — Aislar y proteger datos por usuario.
- **Moderación de contenido** — Filtrar publicaciones antes de mostrarlas.
